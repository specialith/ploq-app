# Ploq Setup (Windows)

`Ploq-<version>-Setup.exe` is the installer ploq.app/download hands out on Windows. It's one screen in the
lander's style: the install folder, the Terms of Service tick box and an Install button, then progress
and "Open Ploq".

It carries the release's `Ploq-<version>.msi` unchanged and runs it through Windows Installer's own API
(`MsiInstallProduct`) with Windows Installer's UI turned off, drawing the progress itself. The .msi
still does the actual install (per user, so no administrator prompt; Start menu; ploq:// links;
uninstall entry). Ploq updates itself from the bare .msi, so auto-updates don't go through this app.

## Files

- `PloqSetup.cs`: the app (WPF, C# 5). Built with the C# compiler and WPF that come with Windows 10/11
  (.NET Framework 4.8), so building and running it needs nothing installed.
- `PloqSetup.manifest`: runs without an administrator prompt (otherwise Windows asks for one just because
  the name contains "Setup"), and keeps it sharp on high-resolution screens.
- `setup-mark.png`: the blurred mark, generated by `make_setup_art.py` from the same geometry as every
  other Ploq icon. Inter comes from `src/collab/fonts`.
- `build_setup.ps1`: builds it.

## Build

```
powershell -File tools\collab\installer\setup\build_setup.ps1 -Msi builds\installer\Ploq-1.0.8.msi
```

That writes `Ploq-1.0.8-Setup.exe` next to the .msi. The GitHub release workflow does the same and attests
both files. `-Preview` also draws every screen (unticked, ticked, installing, done, error, Ploq open) to
PNGs next to the .exe without showing a window.

## Development switches

- `--render out.png <state> [scale]` draws one screen to a PNG (what `-Preview` uses).
- `--install-quiet result.txt` runs the real install with no window and writes the result code and
  the progress it saw. Note that this really installs Ploq.

Windows Installer's log of the last install is `%TEMP%\Ploq-setup.log`; the error screen links to it.
